# 课堂 Boss 战

分组答题互动小游戏（单文件 HTML，无需安装）。

## 文件说明

| 文件 | 用途 |
|------|------|
| `index.html` | 网站首页 / 本地打开 |
| `join/index.html` | 学生扫码加入页 |

## 在线地址

- 首页：`https://james231930.github.io/`
- 学生加入：`https://james231930.github.io/join?room=房间号`

## 使用方式

1. **教师**：打开 `index.html` → 教师端 → 创建房间 → 大屏展示二维码  
2. **学生**：扫码或打开带 `?room=房间号` 的链接，自动填入并加入
