# 课堂 Boss 战

分组答题互动小游戏（单文件 HTML，无需安装）。

## 文件说明

| 文件 | 用途 |
|------|------|
| `课堂Boss战.html` | 本地使用：双击用浏览器打开 |
| `join/index.html` | 学生扫码加入页（内容与主文件相同） |
| `james231930.github.io/` | GitHub Pages 部署仓库，推送到 GitHub 后学生可扫码访问 |

## 使用方式

1. **教师**：打开 `课堂Boss战.html` → 教师端 → 创建房间 → 大屏展示二维码  
2. **学生**：扫码或打开带 `?room=房间号` 的链接，自动填入房间号并加入  
3. **部署**：将 `james231930.github.io` 文件夹推送到 GitHub 仓库 `james231930.github.io`，线上地址为 `https://james231930.github.io/join?room=xxxx`

## 提示

- 同一台电脑多标签页可联机测试  
- 跨设备时房间数据在教师浏览器本地，学生手机需教师在同一网络环境部署线上版本
